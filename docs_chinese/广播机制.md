# 广播机制

本文档介绍 XLA 的广播 (Broadcasting) 语义。

## 什么是广播？

广播是使不同形状的数组在进行算术运算时具有兼容形状的过程。该术语借用于 [NumPy 广播](http://docs.scipy.org/doc/numpy/user/basics.broadcasting.html)。

当对不同 rank 的多维数组之间，或对不同但兼容形状的多维数组之间进行操作时，就可能需要广播。以加法 `X+v` 为例，其中 `X` 是一个矩阵（2 维数组），`v` 是一个向量（1 维数组）。要执行逐元素加法，XLA 需要将向量 `v` 广播到与矩阵 `X` 相同的维度数，方法是将 `v` 复制一定次数。向量的长度必须至少与矩阵的其中一个维度匹配。

例如：

    |1 2 3| + |7 8 9|
    |4 5 6|

矩阵维度为 (2,3)，向量维度为 (3)。通过将向量按行复制，广播后得到：

    |1 2 3| + |7 8 9| = |8  10 12|
    |4 5 6|   |7 8 9|   |11 13 15|

## 原则

XLA 语言尽可能做到严格和明确，避免隐式的"魔法"特性。这类特性可能使某些计算的定义稍微容易一些，但代价是将更多假设固化在用户代码中，长期来看难以更改。如有必要，隐式的魔法特性可以在客户端级别的包装器中添加。

关于广播，XLA 要求对在不同 rank 的数组之间的操作**显式指定广播维度**。这与 NumPy 不同，后者在可能时会自行推断出广播规格。

## 将低维数组广播到高维数组

*标量* 始终可以在不需显式指定广播维度的情况下广播到数组上。标量和数组之间的逐元素二元操作的含义是：使用该标量与数组中的每个元素进行相应的操作。例如，将一个标量加到一个矩阵上，意味着产生一个矩阵，其中每个元素都是该标量与输入矩阵对应元素的和。

    |1 2 3| + 7 = |8  9  10|
    |4 5 6|       |11 12 13|

大多数广播需求可以通过在二元操作上使用一个维度元组来满足。当操作的两个输入的 rank 不同时，该广播元组指定**较高维数组**中的哪些维度与**较低维数组**的维度进行匹配。

考虑前面的例子：将一个维度为 (3) 的向量加到一个维度为 (2,3) 的矩阵上，而不是加一个标量。*不指定广播维度时，此操作是非法的。*要正确请求矩阵-向量加法，将广播维度指定为 (1)，即向量的维度与矩阵的维度 1 匹配。在二维情况下，如果维度 0 代表行、维度 1 代表列，这意味着向量的每个元素将变成一个与矩阵行数相同的列：

    |7 8 9| ==> |7 8 9|
                |7 8 9|

作为更复杂的例子，考虑将一个 3 元素向量（维度 (3)）加到一个 3x3 矩阵（维度 (3,3)）上。在这个例子中有两种广播方式：
1. 广播维度设为 1：每个向量元素变成一列，向量为矩阵的每一行复制一遍。
2. 广播维度设为 0：每个向量元素变成一行，向量为矩阵的每一列复制一遍。

> 注意：将 2x3 矩阵与 3 元素向量相加时，广播维度为 0 是非法的。

广播维度可以是一个元组，用于描述较小维度的形状如何广播到较大维度的形状中。例如，给定一个 2x3x4 的长方体和一个 3x4 的矩阵，广播元组 (1,2) 意味着将矩阵与长方体的维度 1 和维度 2 进行匹配。

这种广播类型在 `XlaBuilder` 的二元操作中使用，当传入 `broadcast_dimensions` 参数时。在 XLA 源码中，这类广播有时被称为 "InDim" 广播。

### 形式化定义

广播属性允许低维数组通过指定高维数组中哪些维度与之匹配，从而适配高维数组。MxNxPxQ 数组与 T 维向量的匹配如下：

              MxNxPxQ
    dim 3:          T
    dim 2:        T
    dim 1:      T
    dim 0:    T

每种情况下，T 必须等于高维数组中对应维度的大小。向量的值随后从匹配维度广播到所有其他维度。

广播元组中维度的顺序必须与低维数组的维度顺序对应：元组的第一个元素指定高维数组中与低维数组维度 0 匹配的维度，第二个元素指定与低维数组维度 1 匹配的维度，以此类推。广播维度的顺序必须是严格递增的。

## 使用退化维度广播 shape 相似的数组

一个相关的问题是广播两个维度数相同但各维度大小不同的数组。与 NumPy 相同，只有当数组*兼容*时才可以广播。两个数组兼容意味着它们所有的维度对都兼容。两个维度兼容当且仅当：
- 它们相等，或
- 其中一个为 1（退化维度）

当遇到两个兼容数组时，结果形状在每个维度索引上取两者中的最大值。

例如：
1. (2,1) 和 (2,3) 广播到 (2,3)
2. (1,2,5) 和 (7,2,5) 广播到 (7,2,5)
3. (7,2,5) 和 (7,1,5) 广播到 (7,2,5)
4. (7,2,5) 和 (7,2,6) 不兼容，无法广播

一种特殊情况也被支持：每个输入数组在不同索引处有退化维度。此时结果是"外积操作"：(2,1) 和 (1,3) 广播到 (2,3)。

## 广播组合

低维数组广播到高维数组**和**退化维度广播可以在同一个二元操作中同时进行。例如，大小为 4 的向量和大小为 1x2 的矩阵可以使用广播维度 (0) 进行加法：

    |1 2 3 4| + [5 6]    // [5 6] 是一个 1x2 矩阵，而非向量

首先，向量通过广播维度被广播为二维（矩阵）。广播维度中的单个值 (0) 表示向量的维度 0 与矩阵的维度 0 匹配，产生一个 4xM 矩阵，其中 M 被选为匹配 1x2 数组中对应维度的大小（即 4x2）。然后，"退化维度广播"将 1x2 矩阵的维度 0 广播以匹配右侧对应维度的大小（即变成 4x2），最后逐元素相加得到 4x2 的结果矩阵。
