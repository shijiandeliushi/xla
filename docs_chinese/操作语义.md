# 操作语义

本文档描述了 [`XlaBuilder`](https://github.com/openxla/xla/tree/main/xla/hlo/builder/xla_builder.h) 接口中定义的操作语义。通常，这些操作与 [`xla_data.proto`](https://github.com/openxla/xla/tree/main/xla/xla_data.proto) 中 RPC 接口定义的操作一一对应。

命名说明：XLA 处理的通用数据类型是包含某种统一类型元素（如 32 位浮点）的 N 维数组。在整篇文档中，*数组 (array)* 用于表示任意维度的数组。为方便起见，特殊情况有更具体和熟悉的名称；例如*向量 (vector)* 是 1 维数组，*矩阵 (matrix)* 是 2 维数组。

---

## 逐元素算术操作

### Abs
逐元素绝对值 `x -> |x|`。

**`Abs(operand)`** — 参数 `operand`: XlaOp，函数的输入操作数。

### Add
逐元素加法。

**`Add(lhs, rhs)`** — 参数 `lhs`/`rhs`: XlaOp，类型 T 的数组。参数形状必须相似或兼容（参见[广播机制](broadcasting.md)）。此变体**不支持**不同秩数组间的操作，除非其中一个操作数是标量。

**`Add(lhs, rhs, broadcast_dimensions)`** — 支持不同维度广播的变体，参数 `broadcast_dimensions`: ArraySlice<int64>，指定目标形状中每个操作数维度对应的维度。

### Atan2
逐元素 atan2 操作。

**`Atan2(lhs, rhs)`** — 同样支持带 `broadcast_dimensions` 的变体。

### Cbrt
逐元素立方根 `x -> cbrt(x)`。支持可选的 `result_accuracy` 参数。

**`Cbrt(operand, result_accuracy)`** — `result_accuracy` 是可选参数，用户可以为有多种实现的单目操作请求精度类型。

### Ceil
逐元素向上取整 `x -> ⌈x⌉`。

**`Ceil(operand)`**

### Clamp
将操作数限制在最小值和最大值之间。

**`Clamp(min, operand, max)`** — 三个参数都是 XlaOp 类型 T 的数组。行为等价于 `min(max(min, operand), max)`。作为受限的广播形式，`min` 和/或 `max` 可以是标量。

### Div
逐元素除法。

**`Div(lhs, rhs)`** — 同样支持带 `broadcast_dimensions` 的变体。

### Erf
逐元素误差函数 `x -> erf(x)`。

### Exp / Expm1
逐元素指数 `x -> e^x` / `x -> e^x - 1`。

### Floor
逐元素向下取整 `x -> ⌊x⌋`。

### Log / Log1p
逐元素自然对数 / `x -> log(1+x)`。

### Logistic (Sigmoid)
逐元素 Sigmoid 函数 `x -> 1/(1+e^{-x})`。

### Maximum / Minimum
逐元素最大值/最小值。

### Mul
逐元素乘法。

### Neg
逐元素取反 `x -> -x`。

### Pow
逐元素幂运算 `lhs^rhs`。

### Rem
逐元素取余。

### Round
逐元素四舍五入（远离零的中途值向远离零方向舍入）。

### Rsqrt / Sqrt
逐元素倒数平方根 / 平方根。

### Sign
逐元素符号函数。

### Sub
逐元素减法。

## 逐元素逻辑与比较操作

### And / Or / Xor / Not
逐元素逻辑操作。支持带 `broadcast_dimensions` 的变体。对于 Pred 类型操作数，行为等价于布尔逻辑；对于整数类型则是按位逻辑。

### Compare
逐元素比较，按 `comparison_direction` 比较 `lhs` 和 `rhs`。

**`Compare(lhs, rhs, direction)`** — `direction` 可取 `kEq`、`kNe`、`kGe`、`kGt`、`kLe`、`kLt`，可选 `kTotalOrder`（支持 TOTALORDER 比较）。结果类型为 `PRED`。

### Select
逐元素选择操作。基于 `pred` 的值从 `on_true` 和 `on_false` 中选择。

**`Select(pred, on_true, on_false)`** — `pred` 是 `PRED` 类型，`on_true` 和 `on_false` 是 T 类型。

## 类型转换操作

### ConvertElementType
执行逐元素类型转换，类似于 C++ 中逐元素的 `static_cast`。

**`ConvertElementType(operand, new_element_type)`** — 参数 `new_element_type`: PrimitiveType。

### BitcastConvertType
类似于 TensorFlow 中的 `tf.bitcast`，执行从数据形状到目标形状的逐元素 bitcast。输入和输出大小必须匹配：例如 `s32` 元素通过 bitcast 成为 `f32` 元素，一个 `s32` 元素将变为四个 `s8` 元素。

**`BitcastConvertType(operand, new_element_type)`**

对于 `B > B'`（输出元素更小），输出形状会获得新的最次要维度，大小为 `B/B'`。对于 `B' > B`，要求输入的最后一个逻辑维度等于 `B'/B`，转换时该维度被丢弃。

## 张量形状操作

### Broadcast
通过复制数组中的数据添加维度。新维度插入在左侧。

**`Broadcast(operand, broadcast_sizes)`** — `broadcast_sizes` 是新维度的大小。

### BroadcastInDim
类似 Broadcast，但允许在任何位置添加维度，并扩展大小为 1 的现有维度。

**`BroadcastInDim(operand, out_dim_size, broadcast_dimensions)`** — `broadcast_dimensions` 将操作数的维度映射到目标形状的维度。

### Collapse
将数组的维度折叠为一个维度。

**`Collapse(operand, dimensions)`** — `dimensions` 是 T 维度的有序连续子集。

### Concatenate
沿指定维度连接多个数组。

**`Concatenate(operands..., dimension)`** — 所有操作数必须具有相同的秩，且除连接维度外所有维度大小相等。

### Reshape
改变数组维度，但保持元素数量不变。

**`Reshape(operand, new_sizes[])`** — `new_sizes` 是新形状。

**`Reshape(operand, dimensions[], new_sizes[])`** — 带有 `dimensions` 参数的变体，指定输入形状的维度在输出形状中的对应维度顺序。

### Slice
从输入数组中提取子数组。

**`Slice(operand, start_indices, limit_indices, strides)`** — `start_indices` 是每个维度的起始索引（包含）；`limit_indices` 是每个维度的结束索引（不包含）；`strides` 是每个维度的步长。

### Transpose
执行数组维度的排列。

**`Transpose(operand, dimensions[])`** — `dimensions` 是排列向量。

### Reverse
反转数组中指定维度的元素顺序。

**`Reverse(operand, dimensions[])`**

### Pad
填充数组边缘或数组间。

**`Pad(operand, padding_value, padding_config)`** — `padding_config` 指定低/高/内部填充量。

## 数据访问操作

### Gather
从数组中收集元素，形成新的数组。概念上类似于非连续内存访问的向量化。

**`Gather(operand, start_indices, offset_dims, collapsed_slice_dims, start_index_map, index_vector_dim, slice_sizes, indices_are_sorted)`**

主要参数：
- `operand`：要收集数据的源数组
- `start_indices`：包含起始索引的数组
- `slice_sizes`：每片的大小
- `offset_dims`：输出形状中偏移维度的集合（即 `slice_sizes` 中不是批量维度的部分）
- `collapsed_slice_dims`：折叠的切片维度集合（大小为 1 的维度）
- `start_index_map`：将 `start_indices` 的每个维度映射到 `operand` 维度的排列
- `index_vector_dim`：`start_indices` 中包含起始索引向量的维度

### Scatter
将 `updates` 数组中的值，根据 `scatter_indices` 指定的索引，通过 `update_computation` 函数写入 `operand` 数组。

**`Scatter(operand, scatter_indices, updates, update_computation, index_vector_dim, update_window_dims, inserted_window_dims, scatter_dims_to_operand_dims)`**

### DynamicSlice
在动态 `start_indices` 处提取子数组。

**`DynamicSlice(operand, start_indices..., slice_sizes)`** — `start_indices` 是每个维度的起始索引（每个都是标量），`slice_sizes` 是切片大小。

### DynamicUpdateSlice
在动态 `start_indices` 处将 `update` 写入 `operand`。

**`DynamicUpdateSlice(operand, update, start_indices...)`**

## 归约与扫描操作

### Reduce
对数组的一个或多个维度应用归约函数。

**`Reduce(operand, init_value, computation, dimensions[])`**

- `init_value`：归约的初始值
- `computation`：任意类型的归约函数 `T, T -> T`
- `dimensions`：要归约的维度

对于 variadic reduce（多个输入和多个初始值），所有输入形状的归约维度必须相同。

### ReduceWindow
在输入数组上滑动窗口并应用归约函数。

**`ReduceWindow(operand, init_value, computation, window_dimensions, window_strides, padding, base_dilations, window_dilations)`**

### SelectAndScatter
类似于 ReduceWindow，但选择从窗口中"选定"的值，并通过 scatter 函数将源值分发到选定的位置上。

### Sort
对数组沿指定维度排序。对于 variadic sort，所有操作数一起排序（键值排序）。

**`Sort(operands..., dimension, comparator)`** — `comparator` 是比较函数 `<`。

### TopK
返回输入中沿最后一个维度的前 k 个最大值/最小值及其索引。

**`TopK(operand, k, largest)`** — `largest`: bool，true 表示最大的 k 个值。

## 线性代数操作

### Cholesky
计算一批对称（Hermitian）正定矩阵的 Cholesky 分解。

**`Cholesky(a, lower)`** — 如果 `lower=true`，计算下三角矩阵 `l` 满足 `a = l · l^T`；如果 `lower=false`，计算上三角矩阵 `u` 满足 `a = u^T · u`。

输入具有 > 2 个维度时，除最小的 2 个维度外都是批量维度。

### Dot
两个数组的点积/矩阵乘法。

**`Dot(lhs, rhs, lhs_contracting_dims[], rhs_contracting_dims[], lhs_batch_dims[], rhs_batch_dims[])`**

- `lhs_contracting_dims` / `rhs_contracting_dims`：收缩维度（即被累加的维度）
- `lhs_batch_dims` / `rhs_batch_dims`：批量维度（即独立执行矩阵乘法的维度）

精确语义见 [StableHLO dot_general](https://openxla.org/stablehlo/spec#dot_general)。

### TriangularSolve
求解三角矩阵方程组。

**`TriangularSolve(a, b, left_side, lower, unit_diagonal, transpose_a)`**

### Eigh / Qr / SVD
特征值分解 / QR 分解 / 奇异值分解。

## 控制流操作

### Call
使用给定参数调用计算体。

**`Call(computation, operands...)`** — 操作数的元数和类型必须匹配 `computation` 的参数。允许没有操作数。

### CompositeCall
封装由其他 StableHLO 操作组成的操作，接受输入和 `composite_attributes` 并产生结果。操作的语义由 `decomposition` 属性实现。可以作为 `kCall` 实现，属性 `is_composite=true`。

### Conditional
根据 `predicate` 的值选择执行 `true_computation` 或 `false_computation`。

**`Conditional(predicate, true_operand, true_computation, false_operand, false_computation)`**

也支持多路分支变体：

**`Conditional(branch_index, branch_computations[], branch_operands[])`**

### While
零次或多次执行 `body`，直到 `condition` 返回 false。

**`While(condition, body, init)`** — `condition` 类型 `T -> PRED`，`body` 类型 `T -> T`，`init` 类型 T。

### OptimizationBarrier
阻止任何 Pass 将操作移动到屏障的另一侧，确保屏障前后的操作独立优化。

### RngBitGenerator
返回填充了均匀随机比特的输出和更新后的生成器状态。

**`RngBitGenerator(algorithm, initial_state, shape)`** — 输出是 `(state, output)` 元组。

## 集合通信操作

### AllGather
跨副本执行连接。

**`AllGather(operand, all_gather_dimension, shard_count, replica_groups, channel_id, layout, use_global_device_ids)`**

输出形状是输入形状的 `all_gather_dimension` 变为 `shard_count` 倍。

### AllReduce
跨副本执行自定义计算。

**`AllReduce(operand, computation, replica_groups, channel_id, shape_with_layout, use_global_device_ids)`**

输出形状与输入形状相同。内部分解为 `AllReduceStart` 和 `AllReduceDone`。

### CrossReplicaSum
使用求和计算执行 AllReduce。

**`CrossReplicaSum(operand, replica_groups)`**

### AllToAll
将所有核心的数据发送到所有核心。

**`AllToAll(operand, split_dimension, concat_dimension, split_count, replica_groups, layout, channel_id)`**

分为两阶段：散射阶段（操作数沿 `split_dimension` 分割并发送）和收集阶段（沿 `concat_dimension` 连接接收的块）。

### RaggedAllToAll
执行不规整张量的 all-to-all 操作。不规整张量由 `data`、`offsets` 和 `sizes` 三个张量定义。

**`RaggedAllToAll(input, input_offsets, send_sizes, output, output_offsets, recv_sizes, replica_groups, channel_id)`**

### CollectiveBroadcast
将数据从一个核心广播到所有核心。

### CollectivePermute
在副本间排列数据。

**`CollectivePermute(operand, source_target_pairs)`**

## 其他操作

### BatchNormTraining / BatchNormInference / BatchNormGrad
批量归一化的训练、推理和梯度计算。

### Convolution
卷积操作。

**`Conv(operand, kernel, window_strides, padding, feature_group_count, batch_group_count, window_reversal, precision_config)`**

### CustomCall
在计算中表示用户定义的操作。

**`CustomCall(call_target_name, operands..., shape, opaque...)`**

### Infeed / Outfeed
向/从设备喂入数据的数据传输操作。

### Iota
创建一个填充了从 0 开始的递增序列的数组。

**`Iota(shape, iota_dimension)`**

### Rng
生成均匀随机分布的数组。

**`Rng(a, b, shape, distribution)`** — `distribution` 是 `RngDistribution` 枚举（UNIFORM 或 NORMAL）。

### Send / Recv
跨设备的数据传输。

### GetTupleElement / Tuple
元组访问和构造。

### BatchNormGrad
计算 Batch Normalization 的梯度。

### StochasticConvert
随机取整类型转换。将浮点数以等于小数部分的概率随机取整到更高或更低的整数。

**`StochasticConvert(operand, random, new_element_type)`**
