# XLA

XLA（加速线性代数，Accelerated Linear Algebra）是一个用于机器学习领域的开源编译器。XLA 编译器接受来自 PyTorch、TensorFlow 和 JAX 等主流框架的模型，并针对 GPU、CPU 以及 ML 加速器等多种硬件平台对这些模型进行优化，以实现高性能执行。

作为 OpenXLA 项目的一部分，XLA 由业界领先的 ML 硬件与软件公司共同协作构建，参与方包括阿里巴巴、Amazon Web Services、AMD、Apple、Arm、Google、Intel、Meta 以及 NVIDIA。

## 核心优势

- **随处构建**：XLA 已集成到 TensorFlow、PyTorch 和 JAX 等主流 ML 框架中。

- **随处运行**：支持包括 GPU、CPU 和 ML 加速器在内的多种后端，并提供可插拔的基础设施以支持更多平台。

- **最大化并扩展性能**：通过经过生产环境验证的优化 Pass，以及模型并行所需的自动分区能力，对模型的性能进行优化。

- **消除复杂性**：利用 [MLIR](https://mlir.llvm.org/) 的强大能力，将各类最佳能力整合到统一的编译器工具链中，使您无须管理一系列特定领域的编译器。

- **面向未来**：作为一个由领先的 ML 硬件和软件供应商协作构建的开源项目，XLA 的设计目标是运行在 ML 行业的最前沿。
