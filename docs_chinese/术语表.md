# XLA 术语表

以下是在 XLA、MLIR、LLVM 及其他相关技术语境中常用的若干术语及其定义。

- **OpenXLA**
    - OpenXLA 是一个开放的生态系统，由高性能、可移植、可扩展的机器学习 (ML) 基础设施组件组成。它通过消除前端框架与硬件后端之间的工具碎片化，简化了 ML 开发流程。OpenXLA 包含 XLA 编译器、StableHLO、VHLO、[PJRT](https://openxla.org/xla/pjrt) 及其他组件。
- **XLA**
    - XLA（加速线性代数）是一个开源的机器学习编译器。它接受来自 PyTorch、TensorFlow 和 JAX 等主流框架的模型，并针对 GPU、CPU 和 ML 加速器等多种硬件平台对模型进行优化以实现高性能执行。XLA 编译器将部分代码输出为 LLVM，部分输出为"标准" MLIR，部分输出为 [Triton MLIR](https://triton-lang.org/main/dialects/dialects.html)，后者由基于 MLIR 的 OpenAI Triton 编译器进一步处理。
- **PJRT**
    - [PJRT](https://github.com/openxla/xla/blob/main/xla/pjrt/c/pjrt_c_api.h) 是一个统一的设备 API，它简化了跨硬件和框架执行 ML 工作负载时日益增长的复杂性。它为编译器和运行时提供了一个与硬件和框架无关的接口。
- **StableHLO**
    - StableHLO 是 OpenXLA 的公共接口，它是一个标准化的 MLIR dialect，可被 OpenXLA 生态系统中的不同框架和编译器所使用。XLA 支持 StableHLO，并在输入端立即将其转换为 HLO。基于 MLIR 框架实现了一些 [StableHLO 到 StableHLO](https://openxla.org/stablehlo/generated/stablehlo_passes) 的 Pass。也可以在不经过 HLO 的情况下将 StableHLO 转换为其他编译器的 IR。
- **CHLO**
    - CHLO 是一组更高级别的操作，可以选择性地被分解为 StableHLO。
- **VHLO**
    - [VHLO Dialect](https://openxla.org/stablehlo/vhlo) 是一个 MLIR dialect，作为 StableHLO 之上的兼容层。它通过对各个程序元素进行版本化来提供 StableHLO dialect 在特定时间点的快照，用于序列化和稳定性保证。
- **MHLO**
    - MHLO 是 XLA HLO IR 的一个独立 MLIR 表示。该 dialect 正在被评估是否要废弃，新用户应优先使用 StableHLO。
- **HLO**
    - HLO（高级优化器，High Level Optimizer）是 XLA 编译器的内部图表示（IR）（也支持作为输入）。它**不**基于 MLIR，拥有自己的文本语法和二进制（基于 protobuf）表示。
- **MLIR**
    - [MLIR](https://mlir.llvm.org) 是一种混合 IR 基础设施，允许用户在不同抽象级别上定义操作的 "dialect"，并在这些操作集之间进行逐步降低，在每个粒度级别上执行变换。StableHLO 和 CHLO 是 MLIR dialect 的其中两个例子。
- **LLVM**
    - [LLVM](https://llvm.org/) 是一个编译器后端，同时也是一种编译器输入语言。许多编译器首先生成 LLVM 代码，然后由 LLVM 生成机器码。这使得不同编译器中相似的代码可以复用，也使得支持不同目标平台更加容易。XLA 的 GPU 和 CPU 后端拥有 [LLVM IR 发射器](https://github.com/openxla/xla/tree/main/xla/service/llvm_ir)，用于针对特定硬件。
